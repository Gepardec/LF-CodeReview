# Ausgangssituation

Die aktuelle Code-Review-Praxis ist 
 - zeitaufwendig, 
 - abhängig von individueller Expertise,
 - häufig inkonsistent

Das Projekt adressiert diese Herausforderungen durch den Einsatz von KI, die:

- Code anhand definierter Coding-Guidelines prüft
- Code gegen funktionale und nicht-funktionale Anforderungen validiert
- Tests daraufhin überprüft, ob Anforderungen vollständig abgedeckt sind
