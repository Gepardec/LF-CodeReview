# Lernziele

- Evaluieren, wie Anforderungen formuliert sein müssen, damit sie für KI-basierte Code-Reviews nutzbar sind
- Evaluieren, wie Coding-Guidelines strukturiert sein müssen, um automatisiert geprüft werden zu können
- Evaluieren, welche Tools es bereits auf den Markt gibt für diese Anforderung
- Analyse der Token-Usage, um Kosten und Effizienz einschätzen zu können
- Praktische Erfahrungen mit dem Zugriff auf Anforderungen via MCP sammeln
