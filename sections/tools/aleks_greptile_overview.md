# Greptile

::one::

### Setup
- OAuth (GitHub, Google …)
- Freigabe pro Repo
- Vorschau des PR-Kommentars schon beim Einrichten

::two::

### Reviews
- Strenge und Confidence-Schwelle einstellbar
- Draft-PRs und Limit für geänderte Dateien
- Auto-Re-Review bei neuen Commits
- Analytics-Dashboard (Reviews, gefundene Bugs)

::three::

### Memory / Kontext
- Custom Rules
- Cross-Repo-Cluster
- Lernt aus 👍/👎 und Antworten, Knowledge Base (beta)
- Integrationen (z. B. Jira, beta)

::four::

### T-REX (beta)
- Startet die Anwendung in einer Sandbox
- Validiert den PR zur Laufzeit
- Bei uns meist blockiert: kein JDK in der Sandbox
