# Fazit: IntelliJ AI Assistant

::one::

### Pro
- Review direkt in der IDE bevor es noch gepushed wird
- Rules im Repo -> reproduzierbar
- Anforderungen live aus Jira (MCP)

::two::

### Contra
- Kein PR-Kommentar, nur IDE-Chat
- Manuell getriggert
- Qualität hängt am Ticket & Modell (Entwickler muss wissen, was ein passendes/ausreichendes Modell für Code Review ist)

::three::


### Fazit
- Der Code Review Skill muss regelmäßig weiterentwickelt werden, da es von unterschiedlichen Agents/Modellen unterschiedliche verarbeitet wird.
- Guter Weg für ein **lokales Review vor dem PR**, aber aktuell noch kein Ersatz für menschliches Review
